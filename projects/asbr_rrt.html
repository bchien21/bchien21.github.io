Manipulator RRT Motion Planner

View Project

Overview

A C++ implementation of the Rapidly-Exploring Random Tree motion planning algorithm, written from scratch for a 6DOF UR5 manipulator to plan a collision-free path inside a vehicle.

High-Level Algorithm

  1. Initialize two trees: startTree rooted at the start configuration (q_init) and goalTree rooted at the goal configuration (q_goal).
  2. Grow startTree first. Sample a collision-free configuration (q_rand), using a 5% goal bias that occasionally sets q_rand to q_goal to guide exploration.
  3. Find the nearest node (q_near) in startTree using Euclidean distance in configuration space, such as squared distance across the six joint values of a 6-DOF robot.
  4. Sample another collision-free configuration (q_rand), then find its nearest node (q_near) in startTree using the same distance metric.
  5. Generate q_new by stepping from q_near toward q_rand along the straight-line path by a fixed proportion of their distance.
  6. If the path from q_near to q_new is collision-free, add q_new to startTree.
  7. Check whether q_new can connect collision-free to a node in goalTree. If so, combine the path from q_init to q_new with the path from that goalTree node to q_goal.
  8. If step 6 or step 7 fails, repeat from step 2 while growing goalTree instead. Alternating the active tree treats q_init and q_goal as swapped targets, improving convergence.
  9. Repeat until a valid path is found or the maximum iteration limit is reached.
