Real-Time 3D LiDAR-based SLAM for a Unitree Go2 Quadruped

View Project

Project Overview

Development of a ROS2-based pipeline that runs real-time, 3D LiDAR-only simultaneous mapping and localization (SLAM) for a Unitree Go2 Quadruped, EDU model. The LiDAR used is a Hesai XT16.
This is a smaller, complementary project worked on during my Hitachi internship.

◆

Pipeline Components

Hesai LiDAR ROS2 Driver

  • Publishes point cloud data to ROS topics.
  • Configured with the IP addresses of the Hesai Lidar and the host PC which broadcasts ROS topics (In this case, the Go2's built-in Jetson Orin Nano).

Kiss-SLAM (Publication)

  • A LiDAR-only SLAM system developed by researchers from the University of Bonn requiring minimal parameter tuning.
  • Configured to point to the point cloud topic published to by the Hesai driver.
